A collection of **Spring Boot REST API Mini Projects** developed using **Java, Spring Boot, Spring Data JPA, MySQL, Bean Validation, DTO Pattern, Exception Handling, and Layered Architecture**.

These projects demonstrate real-world backend development concepts and RESTful API implementation.

---

# 📌 Repository Overview

This repository contains the following Spring Boot applications:

| Project | Description |
|----------|-------------|
| 🎓 Student Course Registration | Manage student course registrations using REST APIs |
| 🍔 Online Food Order System | Manage online food orders and customer searches |
| 🎬 Movie Ticket Booking Application | Book and manage movie tickets |
| 🏥 Hospital Appointment Booking | Manage hospital appointments and doctor scheduling |

# ▶️ Getting Started

## Clone Repository

```bash
git clone https://github.com/AnnaReddybandi/Spring-boot-4-miniprojects.git
```

## Navigate

```bash
cd Spring-boot-4-miniprojects
```

Open any project individually in IntelliJ IDEA.

Configure MySQL credentials in:

```
application.properties
```

Run the corresponding Spring Boot Application class.
